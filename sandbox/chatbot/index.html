How Pip chose the last reply

Send a message and this shows every candidate reply, where it came from and its score. Pip picks the best one.

What's inside

Rules and a knowledge base answer the things they can answer exactly: math, Minecraft recipes, memory and games. For open chat, the retrieval network scores about 58,000 lines from public dialogue datasets, and PipGPT writes a few replies of its own. The same network scores both kinds.

What Pip remembers about you

Stored only in this browser. Pip learns these from normal conversation ("my favorite color is blue", "I have a dog named Rex").

    Clearing the window keeps Pip's memory. Use "Forget everything" in the Memory tab to wipe that too.
